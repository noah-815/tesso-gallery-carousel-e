## 동작

| 항목 | 내용 |
|---|---|
| 전환 | 가로 슬라이드(translateX) 500ms. 다음: 현재 이미지가 왼쪽으로 나가고 다음 이미지가 오른쪽에서 들어옴 |
| 전환 옵션 | **화면 밖에서**(기본, 시안 주석): 박스에서 자르지 않고 화면(390 프레임) 가장자리에서 자름. 이미지 사이 간격 16(섹션 좌우 여백) → 다음 이미지가 화면 오른쪽 끝 바로 밖에서 밀려들어오고, 나가는 이미지는 화면 왼쪽 밖으로 나감 · **박스 안**: 이미지 박스 가장자리에서 잘린 채 두 장이 함께 밀림 |
| 루프 | 마지막 ↔ 처음도 같은 방향으로 이어서 슬라이드 |
| 자동 넘기기 | 데모 패널에서 on / off, 간격 2–5초 (기본 on · 3초) |
| 조작 | 스와이프/드래그, 인디케이터 클릭, 키보드 ← → |
| 인디케이터 | 최대 4개. 진행 방향에 이미지가 더 남아 있으면 활성 dot 이 끝이 아니라 끝에서 두 번째 칸에 머물고 줄이 한 칸씩 밀림. 끝에 도달하면 마지막 칸으로 |
